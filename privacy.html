隱私權與使用規範

這個網站是大學專題「給失聲者用的無聲溝通系統」的資料收集與分析工具。錄影或上傳之前，請先讀完這一頁。

重點摘要

  • 🎯
    只用於本專題：訓練與測試唇語辨識、專題報告與展示。
  • 👄
    盡量只存嘴巴：引導錄影預設只存嘴巴特寫；數據庫只存數字，沒有影像。
  • 🔒
    只有團隊看得到：要有通關碼才能使用，影片只分享給專題成員。
  • ⏳
    有保存期限：專題總截止日後 1 年全部刪除。
  • 🙋
    可以隨時撤回：想刪掉自己的資料，聯絡專題負責人就會刪除。
  • 🚫
    不公開影片：報告和展示只用統計數字與嘴型動畫。

2. 用途

資料只用於本專題：

  • 建立範本、測試與改進唇語辨識的準確率
  • 專題報告、期中／期末展示：只使用統計數字（例如準確率、混淆矩陣）與嘴型輪廓動畫，不播放或公開任何人的影片

不會用於本專題以外的研究、商業用途，也不會提供給專題成員以外的人。若之後想延伸用途，會另外取得同意。

3. 誰看得到

  • 專題成員：持有團隊通關碼的人可以上傳、看分析報告；影片資料夾只分享給專題成員的 Google 帳號。
  • 管理員（專題負責人）：另外可以刪除資料。
  • 指導老師：只看專題報告中的統計結果。

網頁程式碼放在公開的 GitHub repo，但裡面沒有任何資料、密碼或通關碼；資料都在需要通關碼才能讀取的地方。

4. 保存期限

資料保存到專題總截止日後 1 年，期滿後由專題負責人刪除所有影片、口型數據與上傳紀錄（刪除整個 GitHub 資料 repo 與雲端硬碟影片資料夾，版本紀錄也一併消失）。

5. 你的權利

  • 自願參與：不參與不會有任何影響。
  • 查看：可以請專題負責人告訴你，資料庫裡有哪些你的資料。
  • 撤回同意、要求刪除：隨時都可以，不需要理由。專題負責人會刪除你錄製者代號底下的全部影片與口型數據：雲端影片先移到垃圾桶，30 天後永久刪除；口型數據會立刻從資料庫移除、不再被使用，但技術上仍會留在 GitHub 的版本紀錄裡，直到保存期限屆滿、整個資料庫刪除為止。已經寫進報告的匿名統計數字無法回溯修改。
  • 未滿 18 歲：需要法定代理人同意後才能參與。

6. 使用規範

✓ 可以

  • 錄你自己，或是已經同意參與的人
  • 用代號當錄製者名稱
  • 把網址和通關碼給專題成員與同意參與的受試者
  • 發現錄錯或拍到不該拍的，請管理員刪除

✗ 不可以

  • 偷拍、或錄沒有同意的人
  • 把通關碼、管理員密碼貼到公開的地方
  • 下載、轉傳別人的影片到專題以外的地方
  • 上傳跟專題無關的內容，或故意灌爆資料

違反規範的帳號會被要求停止使用，相關資料會被刪除；通關碼外洩時會立即更換。

7. 安全措施

  • 網站全程 HTTPS；沒有通關碼讀不到任何資料，密碼錯太多次會暫停一分鐘
  • 通關碼、GitHub 存取權杖只放在後端服務，網頁程式碼裡沒有
  • 資料 repo 為私有；每次新增、刪除都有紀錄，可以追查
  • 網站設定為不讓搜尋引擎收錄

8. 聯絡窗口

有任何問題、想查看或刪除自己的資料，請聯絡提供你通關碼的專題負責人。
